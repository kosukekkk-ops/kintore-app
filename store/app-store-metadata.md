## 説明（Description）

```
筋トレの記録に、睡眠・食事・サプリメントまで。身体づくりの3本柱をひとつのアプリでまとめて管理できるトレーニング記録アプリです。

トレーニングだけを頑張っても、寝ていない・食べていなければ身体は変わりません。
「今週は追い込めているのに伸びない」——その原因が睡眠なのか、たんぱく質なのか。3本柱を並べて見えるようにしました。

■ こんな方におすすめ
・筋トレを続けているのに伸び悩んでいる方
・トレーニング・食事・睡眠をバラバラのアプリで記録していて面倒な方
・サプリメントの飲み忘れを減らしたい方
・紙のノートやメモアプリから乗り換えたい方

■ ワークアウト記録
・88種目を最初から収録。オリジナル種目の追加も自由
・重量×回数をタップで素早く入力。前回の記録がその場に出るので迷わない
・種目ごとに動作イラストと「鍛える筋肉」「フォームのポイント」つき
・有酸素は時間と距離で記録
・ウォームアップのセットは総量から除外
・インターバルタイマー(既定3分)。時間になると音とバイブでお知らせし、止めるまで鳴り続けます
・1RM計算機つき

■ 睡眠・食事・体重
・就寝と起床の時刻から睡眠時間を自動計算。睡眠の質も5段階で記録
・朝・昼・夕・間食ごとにカロリーとたんぱく質を記録
・体重の推移をグラフで確認
・「今日は休養日」「食事を記録しない日」もそのまま残せます

■ サプリメント管理
・プロテイン、クレアチン、EAAなど定番18種からタップで登録
・朝・トレ前・トレ後・就寝前など、飲むタイミングごとにチェックリスト表示
・「トレーニングした日だけ」の設定にも対応
・飲み忘れは順守率としてグラフに出ます

■ 振り返り
・今週どの柱を記録できたかが一覧でわかる記録状況ビュー
・運動・睡眠・たんぱく質の達成度を目標に対する割合で表示
・カレンダーと履歴から過去の記録をいつでも修正できます
・記録し忘れた日も、あとから日付を選んで埋められます

■ 使いやすさ
・完全オフライン対応。ジムの地下でも電波を気にせず使えます
・ログイン不要・アカウント登録なし・広告なし
・記録データは端末内にのみ保存され、外部に送信されません
・ダークテーマ。アクセントカラーはライム/オレンジから選べます
・日本語 / English 対応

■ 料金
記録機能はすべて無料・無制限でお使いいただけます。
プレミアム(買い切り・サブスクではありません)で以下が解放されます。
・種目別の推移グラフ、自己ベスト、部位別のボリューム配分
・3本柱の14日推移グラフ
・メニューの保存が無制限に(無料版は3件まで)
・サプリメントの登録が無制限に(無料版は3件まで)
・バックアップの書き出し(JSON)

■ ご注意
本アプリは医療機器ではなく、医学的な診断・助言を行うものではありません。表示される数値は入力値にもとづく目安です。体調やけがに関する判断は必ず医師にご相談ください。トレーニングはご自身の責任と判断において安全に行ってください。
```

## 無料 / プレミアムの線引き

記録アプリで記録そのものを制限すると即アンインストールされるため、
**入力・保存は一切制限しない**。制限するのは「積み上げ」と「分析」のみ。

| | 無料 | プレミアム |
|---|---|---|
| ワークアウト・セット記録 | 無制限 | 無制限 |
| 種目の追加（カスタム含む） | 無制限 | 無制限 |
| 睡眠・食事・体重の記録 | 無制限 | 無制限 |
| 履歴・カレンダー | ○ | ○ |
| バランス（記録状況・7日達成度） | ○ | ○ |
| バランスの14日推移グラフ | ✕ | ○ |
| 種目別グラフ・自己ベスト・部位別ボリューム | ✕ | ○ |
| メニュー（テンプレート） | 3件まで | 無制限 |
| サプリの登録 | 3件まで | 無制限 |
| バックアップの書き出し | ✕ | ○ |

実装は `docs/js/premium.js` の `LIMITS` が単一の出典。
`node tools/test-premium.js` で無料/購入済み/復元/返金の各状態を自動検証している。
