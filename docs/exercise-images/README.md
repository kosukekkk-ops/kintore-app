# 種目の説明画像の差し替え方

種目情報シート（ⓘ）の「動作イメージ」は、通常はコードで描いた自作SVGを表示します。
このフォルダに画像を置くと、**その画像を優先して表示**します（無ければ自動でSVGに戻ります）。

## 置き場所とファイル名
- 置き場所: `docs/exercise-images/`（このフォルダ）
- ファイル名: **`<ポーズ名>.png`**（`.jpg` も可。PNG→JPG→SVGの順に探します）
- 画像は動作パターン（ポーズ）単位です。**1枚で、その動作の全種目に反映**されます（約30枚で全83種目をカバー）。
- 推奨: 横長〜正方形、幅600〜1000px程度。表示幅は最大320pxです。

例）`bench.png` を置く → ベンチプレス系すべてがその画像になります。

## 手順
1. 画像をこのフォルダに `bench.png` などの名前で置く
2. `git add docs/exercise-images/bench.png && git commit -m "add bench image" && git push`
3. 数分後に公開サイトへ反映（スマホはアプリ/タブを開き直す）
4. 置いていないポーズは自動でSVG図のまま
